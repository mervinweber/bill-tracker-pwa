# Archived Documentation

These files are preserved for historical reference and auditability.
They are intentionally moved out of the project root to reduce confusion for users and contributors.

## Folders
- `legacy-planning/`: prior planning docs, review summaries, and superseded checklists
- `feature-summaries/`: one-off feature/fix writeups
- `session-reports/`: session completion and temporary checklist notes

If information here is still relevant for active workflows, migrate it into `docs/guides/` and keep this archive as read-only history.
